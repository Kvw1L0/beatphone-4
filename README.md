# Beatphone 4

Juego colaborativo móvil: el equipo debe completar 4.800 movimientos. Cada persona aporta 300 movimientos y el teléfono se bloquea hasta que el siguiente participante confirme que está listo.

- Los toques suman 5 movimientos.
- Las sacudidas detectadas por el acelerómetro suman 1 movimiento.
- Participan 16 personas como mínimo.

Es un sitio estático: basta abrir `index.html` o desplegar la carpeta en Vercel.
